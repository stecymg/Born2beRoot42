Q : Différencen entre Debian et CentOS ?
R : Debian est composé de logiciels libres. Il est adapté aux serveurs et est beaucoup plus stable. Il prend moins de place dans le disque dur. 
    CentOS a été conçu pour fonctionner avec Red Hart Linux. Son interface est plus difficile. 

Q : Pourquoi j'ai choisi Debian ?
R : Car plus facile donc plus adapté aux débutants.

Q : Qu'est-ce-qu'une machine virtuelle ? La virtualisation ? 
R : Une machine virtuelle est un environnement virtuel qui fonctionne comme un système informatique virtuel, avec son propre processeur, sa mémoire, son interface réseau et son espace de stockage. La virtualisation consiste à créer des versions virtuelles. On peut exploiter plusieurs systèmes d'exploitation et exécuter de nombreuses applications sur un seul serveur.

Q : À quoi sert une VM ?
R : Elle permet d'exécuter simultanément plusieurs systèmes d'exploitation sur un seul ordinateur, comme par exemple une distribution Linux sur un ordi portable sous MacOS.

Q : Quel est son but ?
R : Disposer de nombreux serveurs virtuels sur un serveur physique.

Q : Différence entre Aptitude et Apt ? 
R : Aptitude est un gestionnaire de package de haut niveau tandis qu'Apt est un gestionnare de package de niveau inférieur. Aptitude a des fontionnalités plus vaste.

Q : Qu'est-ce-que AppArmor ?
R : "Application Armor" est un logiciel de sécurité pour linux qui permet à l'administrateur système d'associer à chaque programme un profil de sécurité.

Q : Qu'est-ce-que la SSh ?
R : Secure Shell est un protocole de communication réseau qui permet à deux ordinateurs de communiquer et partager des données en tout sécurité.

Comment changer le Hostname ?
hostnamectl ou hostname                                    <- check le hostname actuel 
hostnamectl set-hostname newhostname                       <- pour changer le hostname
sudo nano /etc/hostname    OU    sudo nano /etc/hosts      <- changer avec le nouvel hostname
sudo reboot                                                <- redémarrer 



Comment ajouter et supprimer le port 8080 dans UFW ?
sudo ufw delete 22                 <- suppimer le port 22
sudo ufw allow 8080                <- creer un ufw 
sudo ufw status numbered           <- check si bien ajouté
sudo ufw delete 8080               <- supprimer le 8080 créer
